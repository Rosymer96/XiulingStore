# 🛍️ XiulingStore

¡Bienvenido a **XiulingStore**! Este es un proyecto de comercio electrónico diseñado con un enfoque moderno, funcional y estético. La aplicación permite a los usuarios explorar productos, gestionar su carrito de compras y experimentar una interfaz de usuario fluida.

🚀 **Puedes ver el proyecto en vivo aquí:** [XiulingStore Demo](https://rosymer96.github.io/XiulingStore/)

---

## ✨ Características

* **Diseño Responsive:** Optimizado para dispositivos móviles, tablets y escritorio.
* **Catálogo Dinámico:** Visualización de productos con detalles específicos.
* **Carrito de Compras:** Gestión en tiempo real de productos seleccionados.
* **Interfaz Intuitiva:** Experiencia de usuario (UX) centrada en la facilidad de navegación.

## 🛠️ Tecnologías Utilizadas

El proyecto fue construido utilizando las siguientes herramientas:

* **HTML5 / CSS3:** Estructura y estilos personalizados.
* **JavaScript (ES6+):** Lógica del lado del cliente y manipulación del DOM.
* **GitHub Pages:** Despliegue y hosting del sitio.

## 🚀 Instalación y Configuración

Si deseas ejecutar este proyecto de forma local, sigue estos pasos:

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/Rosymer96/XiulingStore.git
    ```
2.  **Navega al directorio del proyecto:**
    ```bash
    cd XiulingStore
    ```
3.  **Abre el archivo principal:**
    Simplemente abre el archivo `index.html` en tu navegador favorito.
